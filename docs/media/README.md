# 展示素材清单

把录好的文件按下面的名字放进这个目录，主 README 会自动显示。详细效果说明写在主 README 对应位置的注释里。

| 文件 | 类型 | 内容 | 尺寸建议 |
|---|---|---|---|
| `icon.png` | PNG | App 图标（可选，没有就删掉 README 顶部那行） | 256×256 |
| `hero.png` | 截图 | 桌面上悬浮的小窗，「同步完成」+ 提示条 | 宽 ~1600 |
| `sync.gif` | 动图 ⭐ | 点按钮 → 预览列表 → 逐个打勾 → 完成提示 | 宽 720，8–12s，<8MB |
| `picker.gif` | 动图 | 设置里浏览并点选 OneDrive 文件夹 | 宽 600，6–8s |
| `conflict.png` | 截图 | 橙色冲突条目 + 冲突副本卡片 | 宽 600 |
| `brake.png` | 截图 | 删除超过 10% 的确认卡片 | 宽 600 |
| `styles.png` | 拼图 | 液态玻璃 / 磨砂 / 超透明 对比 | 宽 1200 |

录制工具：Kap（免费）或 CleanShot X；GIF 用 15fps，过大可以用 `gifski` 压缩。
